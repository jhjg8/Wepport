 ในงาน Roblox booth camp, Sci Game, Ai kick starter1 และ Ai kick starter2 เป็นกิจกรรมสำหรับศึกษาการสร้างเกมภายใน 3 วันไม่ว่าจะเป็นการใช้ Ai, การเชื่อมต่อ Game engineเข้ากับ Mcp, หลักการการสร้าง/ออกแบบเกมและอื่นๆอีกมากมาย
       ในกิจกรรมผมมีบทบาทหน้าที่ในการช่วยสร้างบรรยากาศ ตอบคำถามต่างๆของผู้เรียน และช่วยผู้เรียนที่มีปัญหาในการทำเกม ส่วนมากจะเป็นการที่ Ai ลืมสิ่งที่ตัวเองทำไปทำให้บาง class ซ้ำกัน, setting Game engine ผิดโดบเฉพาะ Input package และอีกมากมาย
       จากการเปลี่ยนมุมมองของผู้เรียนเป็นผู้สอนทำให้ผมได้เข้าใจมุมมองของผุ้สอนว่า เขาไม่ได้รู้ทุกอย่างยิ่งผมได้ศึกษามามากมายขนาดนี้แล้วนั่นหมายความว่าผู้ที่สามารถสอนผมได้จะยิ่งมีน้อยลง นั่นจึงเป็นแรงผลักดันให้ผมได้พยายามศึกษาและเรียนรู้ด้วยตัวเองไปเรื่อยๆ

       ในตอนนั้นผมได้รับมอบหมายให้ทำ Assets สำหรับผู้เข้าเรียนหน้าใหม่ที่ยังทำอะไรไม่เป็น อย่างน้อยเข้าจะได้มีตัวอย่างโปรแกรมที่ถูกกต้องและเป็นการประหยัดเวลาการทำงานด้วย เพื่อความสะดวกของผู้เรียน
       ผมจึงนึกถึงเกมแรกที่อยากทำตอนเพิ่งเรียนใหม่ๆ นั่นคือเกม turn-base ผมจึงตัดสินใจที่จะสร้าง Game turn-base Template ขึ้นมาเนื่องจากระบบมีความยากต่อการเข้าใจสำหรับมือใหม่และเป็นแนวเกมที่ผู้คนนิยมเล่นอีกด้วย ผลงานนี้ผมตั้งใจทำโดยใช้ Partial class และแยก Assets ของผมออกเป็น 3 แบบโดยไม่ว่าผู้ใช้จะต้องการเกม Turn-base แบบไหนผมก็มีให้ทั้งหมดไม่ว่าจะเป็น ระบบตำแหน่งของ unit ระบบ Status effect ที่นิยมในหลายๆเกม และแบบธรรมดาซึ่งง่ายต่อการนำไปต่อ ยอด จากทุกระบบที่ผมได้กล่าวไปคุณสามารถใส่หลายระบบพร้อมกันเพื่อสร้างเกม turn-base ในแบบที่คุณต้องการได้
